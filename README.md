# مطبخ U ثلاثي الأبعاد

صفحة واحدة مستقلة (index.html) تعمل بدون إنترنت، ومكتبة three.js مدمجة بداخلها.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (Public) على GitHub.
2. ارفع الملفات: `index.html` و `.nojekyll` و `README.md`.
3. من Settings ← Pages ← Source: اختر Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)`، ثم Save.
4. بعد دقيقة تقريباً يظهر الرابط: `https://USERNAME.github.io/REPO/`
